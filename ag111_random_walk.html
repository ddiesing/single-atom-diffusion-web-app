About the model
  • Thermally activated hops on a triangular lattice of hollow sites. Same model as the classroom Monte Carlo. J.P. Meyburg & Detlef Diesing, J. Chem. Educ. 2017, 94, 1225–1231
  • Layer B is dark, layer C is light; the adatom sits one stacking vector above C.
  • The trail is one disk per visited site; revisits only change colour and opacity.
Simulation notes
  • Periodic boundaries. Six equivalent nearest-neighbour hops.
  • Start = white disk with a horizontal bar; current position = vertical bar.
  • For terraces larger than 100×100, layers B and C are drawn as filled parallelograms with atoms only on the rim.

Controls

Musical notes for individual hops (about 8.3 hops per second).

Physical model

Thermally activated hopping rate

\[ k_{\mathrm{dir}} = \nu_0 \exp\left( -\frac{E_{\mathrm a}}{k_{\mathrm B}T} \right) \]

Total hopping rate

\[ \Gamma = 6 k_{\mathrm{dir}} \]

Mean waiting time

\[ \langle\tau\rangle = \frac{1}{\Gamma} \]

Random waiting time for each hop

Random waiting time for each hop

\[ \Delta t = -\frac{\ln U}{\Gamma}, \qquad 0 \lt U \lt 1 \]

Model parameters

\[ \begin{aligned} \nu_0 &= 5\times10^{12}\,\mathrm{s}^{-1}\\ E_{\mathrm a} &= 0.10\,\mathrm{eV} \end{aligned} \]

Animation speed is not physical time. The displayed simulation time t is physical time.
